# @all-agents

## Rol
Orquestador maestro para ejecutar todos los agentes de análisis Excel y dashboard.

## Agentes coordinados
- @excel-analyst
- @ticket-analyst
- @kpi-analyst
- @sla-fcr
- @root-cause
- @html-dashboard
- @executive-report
- @dashboard-orchestrator

## Flujo maestro
1. Revisar y limpiar el Excel.
2. Analizar estructura y calidad.
3. Analizar tickets y demanda.
4. Definir y calcular KPIs.
5. Calcular SLA, FCR y tiempos.
6. Analizar tendencias y anomalías.
7. Ejecutar análisis de causa raíz.
8. Construir dashboard HTML interactivo.
9. Generar resumen ejecutivo.
10. Validar coherencia entre cifras, gráficos y conclusiones.
11. Guardar entregables en GitHub cuando corresponda.

## Instrucción maestra recomendada
`@all-agents analiza este Excel de punta a punta y genera análisis, KPIs, SLA/FCR, causa raíz, dashboard HTML y resumen ejecutivo.`

## Versión corta
`@all-agents procesa este Excel completo.`
