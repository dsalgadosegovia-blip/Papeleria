## Flujo
1. Validar y limpiar datos.
2. Analizar métricas y segmentos.
3. Detectar tendencias y anomalías.
4. Ejecutar causa raíz.
5. Crear resumen ejecutivo humanizado.
6. Definir historia y jerarquía del dashboard.
7. Diseñar UI/UX con criterios de Product Design.
8. Implementar interactividad.
9. Aplicar acabado visual.
10. Construir dashboard HTML responsive.
11. Validar números, filtros, gráficos y textos.
12. Generar conclusiones y acciones.

## Requisitos
- Dashboard HTML profesional.
- Interactivo y responsive.
- KPI cards.
- Filtros globales.
- Drill-down cuando aporte valor.
- Gráficos coordinados.
- Narrativa breve dentro del dashboard.
- Resumen ejecutivo humanizado.
- Alertas de calidad de datos.
- Recomendaciones accionables.

## Instrucción maestra
`@pro-dashboard-master analiza este Excel y genera un dashboard HTML profesional, interactivo y ejecutivo, con análisis resumido, lenguaje humanizado, causa raíz y recomendaciones.`

## Versión corta
`@pro-dashboard-master procesa este Excel y crea el dashboard profesional completo.`
