# Agentes ChatGPT para Excel y Dashboards

Este paquete define agentes reutilizables para trabajar desde ChatGPT con Excel, Data Analytics, Build Web Data Visualization y GitHub.

## Llamados rápidos

- **@excel-analyst** — analiza un Excel, limpia datos, detecta estructura, KPIs, anomalías y tendencias.
- **@kpi-analyst** — diseña y valida KPIs, metas, SLA, FCR, TMO, backlog y segmentaciones.
- **@html-dashboard** — transforma análisis en un dashboard HTML interactivo y responsive.
- **@dashboard-orchestrator** — coordina todo el flujo Excel → análisis → KPIs → dashboard HTML → GitHub.

## Ejemplos

```
@dashboard-orchestrator analiza este Excel y genera un dashboard HTML ejecutivo.
```

```
@excel-analyst revisa este archivo, detecta problemas de calidad y dame los 10 principales hallazgos.
```

```
@html-dashboard usa el análisis anterior y crea un dashboard con filtros por fecha, técnico, sucursal y estado.
```
